# 📱 MeeGo Launcher for Android

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Platform: Android](https://img.shields.io/badge/Platform-Android-brightgreen.svg)](https://developer.android.com/about)

**MeeGo Launcher** es un lanzador de aplicaciones ligero y elegante para Android, inspirado en la mítica interfaz de usuario **Harmattan** del Nokia N9. Diseñado especialmente para ofrecer una experiencia fluida y minimalista en tablets y teléfonos.

---

## ✨ Características principaless

* **Interfaz de 3 Paneles:** * **Feed:** Reloj estilo MeeGo, clima en tiempo real (vía Open-Meteo) y notificaciones unificadas.
    * **App Grid:** Rejilla de aplicaciones altamente personalizable (3 a 6 columnas).
    * **Switcher:** Gestor de aplicaciones recientes para una multitarea real.
* **Gestos Intuitivos:** Swipe vertical para invocar un **Dock dinámico** desde cualquier pantalla.
* **Personalización Extrema:** Soporte nativo para **Icon Packs** de terceros.
* **Gestión de Apps:** Desinstala aplicaciones o accede a su información directamente con un toque largo.
* **Privacidad Primero:** Sin telemetría, sin anuncios y sin trackers. Solo código puro.

## 🚀 Instalación

### GitHub
1. Ve a la sección de [Releases](https://github.com/TU_USUARIO/MeeGo-Launcher/releases).
2. Descarga el último APK disponible.
3. Instala en tu dispositivo (asegúrate de permitir la instalación desde orígenes desconocidos).

---

## 🛠️ Desarrollo (Tech Stack)

Este proyecto está construido con las últimas tecnologías de Android:
* **Kotlin** como lenguaje principal.
* **Jetpack Compose** para una interfaz de usuario declarativa y reactiva.
* **Corrutinas de Kotlin** para un rendimiento fluido y manejo de datos en segundo plano.
* **Accompanist** para la gestión avanzada de iconos y recursos gráficos.
